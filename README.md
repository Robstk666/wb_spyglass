# 🤖 WB Competitor Analyzer

Бот для анализа конкурентов на Wildberries.
**Вход**: артикул товара. **Выход**: топ-5 конкурентов + отчёт.

---

## ⚡ Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить (токен получится автоматически через браузер)
python analyze.py 123456789

# 3. Или с готовым токеном (быстрее)
python analyze.py 123456789 --token "eyJ0eXAiOiJ..."
```

## 🔑 Главная проблема: защита WB (май 2026)

> **Это то, почему большинство готовых парсеров не работают.**

WB использует **JS-challenge** при первом открытии сайта.
После прохождения проверки браузер получает cookie **`xwb-token`** (живёт ~2 недели).

Без этого токена `search.wb.ru` возвращает **HTTP 498** — и ничего не работает.

### Как мы это решаем

Логика взята из видео [Parsub — Парсинг WB 2024, обход защиты](https://www.youtube.com/watch?v=uYdsXeX3X-0):

1. Открываем WB через **undetected-Chrome** (Selenium с патчами против детекции)
2. Браузер сам решает JS-challenge (как настоящий пользователь)
3. Забираем `xwb-token` из cookies через CDP
4. Сохраняем в файл `.token` — больше не нужно открывать браузер ~2 недели
5. Все последующие запросы идут через `requests` с этим токеном

```
WB сайт → Chrome (undetected) → xwb-token → requests → search.wb.ru ✅
```

### Получить токен вручную (альтернатива)

Если seleniumbase не ставится или Chrome недоступен:

1. Открой браузер, перейди на `wildberries.ru`
2. F12 → Application → Cookies → `wildberries.ru`
3. Найди строку `xwb-token`, скопируй значение
4. Передай в команду: `python analyze.py 123456789 --token "ЗНАЧЕНИЕ"`
5. Или сохрани в файл `.token` (одна строка)

## 🧠 Как работает анализ конкурентов

### Источник данных

Используется **открытый API WB** (тот же, что браузер):

```
GET https://search.wb.ru/exactmatch/ru/common/v18/search
    ?appType=1&curr=rub&dest=-1257786&lang=ru
    &query=джинсы+женские&resultset=catalog&sort=popular&spp=30
```

URL и параметры взяты из статьи [Парсинг WB на Python (Amvera/Habr)](https://habr.com/ru/companies/amvera/articles/).

### Алгоритм поиска конкурентов

```
Артикул (123456789)
    ↓
1. Ищем товар по артикулу в поиске → получаем название + цену
    ↓
2. Берём первые 3 слова названия → поисковый запрос
   "Джинсы женские прямые синие" → запрос: "Джинсы женские прямые"
    ↓
3. Получаем первые 100 товаров из выдачи
    ↓
4. Фильтруем по цене: ±30% от цены основного товара
    ↓
5. Считаем demand_score для каждого
    ↓
6. Сортируем по demand_score ↓ → берём топ-5
```

### Метрика «силы» конкурента: demand_score (0-100)

```
demand_score = (отзывы × 40%) + (рейтинг × 30%) + (продажи × 30%)
```

| Компонент | Вес | Формула | Почему |
|-----------|-----|---------|--------|
| Отзывы | 40% | min(feedbacks/1000, 1) × 100 | Прямой показатель спроса |
| Рейтинг | 30% | rating × 20 | Качество товара |
| Продажи | 30% | min(feedbacks×12/10000, 1) × 100 | ~12 продаж на 1 отзыв |

| Диапазон | Смысл |
|----------|-------|
| 0–30 | Слабый конкурент (мало отзывов) |
| 31–60 | Средний (есть история) |
| 61–80 | Сильный (популярный товар) |
| 81–100 | Доминирующий (лидер сегмента) |

## 🚀 Варианты использования

### Разовый анализ
```bash
python analyze.py 123456789
```

### С сохранением JSON (для интеграций)
```bash
python analyze.py 123456789 --json
# → report.json
```

### Показать топ-10 вместо 5
```bash
python analyze.py 123456789 --top 10
```

### Видеть браузер при получении токена
```bash
python analyze.py 123456789 --no-headless
```

### Еженедельный мониторинг (cron)
```bash
# Добавить в crontab -e:
0 9 * * 1 cd /path/to/wb_bot && python analyze.py 123456789 --json >> monitor.log
```

### Программный доступ
```python
from wb_api import WBClient

client = WBClient(token="ваш_токен")
main, competitors = client.find_competitors(123456789, top_n=5)

for c in competitors:
    print(f"{c.name}: {c.price} ₽, score={c.demand_score}")

# Проверка позиции в поиске
rank = client.get_rank(123456789, "джинсы женские")
print(f"Позиция: {rank}")
```

## ❓ Частые проблемы

### `HTTP 498` при запросе
Токен невалиден или устарел. Решения:
- Удалить файл `.token` и перезапустить (браузер получит новый)
- Или получить вручную (см. выше)

### `seleniumbase не установлен`
```bash
pip install seleniumbase
```
Если не ставится — получи токен вручную через DevTools.

### Товар не найден
Попробуй артикул из URL страницы товара:
`wildberries.ru/catalog/**123456789**/detail.aspx`

### Конкурентов мало или нет
- Сегмент очень узкий (мало аналогов в ценовом диапазоне)
- Или поисковый запрос из названия не подходит → можно доработать метод `_find_by_article`
